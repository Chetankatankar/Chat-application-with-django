# Chat-application-with-django

A simple chat application built with Django that enables users to communicate through a clean and intuitive interface. This project demonstrates Django fundamentals, including user authentication, routing, templates, and database integration, making it a great learning resource for beginners.

Also in most of the chat application's uses tools like websocket for live-long connection means always chat application are real time
